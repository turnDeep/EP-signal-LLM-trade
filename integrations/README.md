# integrations/ - Integration Layer

This layer packages the memory, patterns, validators, and modules so every
Codex session can operate with the same rules.

## Entry Points

- `../CODEX.md`: default Codex operating manual.
- `../SPEC.md`: project constitution.
- `manifest.json`: machine-readable index of the kit.
- `team.install.md`: onboarding checklist for humans and AI sessions.

## Standard Team Flow

1. Start with `CODEX.md`.
2. Load the matching pattern from `patterns/`.
3. Assign one module owner from `modules/`.
4. Implement or analyze.
5. Run `validators/preflight.ps1`.
6. Report changes and verification.
