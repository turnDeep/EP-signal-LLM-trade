# Module: 01 Spec Steward

## Mission

Keep the project constitution accurate and make ambiguous requests executable.

## Responsibilities

- Read `SPEC.md`, `CODEX.md`, and the relevant pattern before implementation.
- Identify the target repo or folder inside the multi-repo workspace.
- Translate vague goals into acceptance criteria.
- Protect project conventions, naming, output structure, and safety rules.

## Output Contract

- Task type and matching pattern.
- Target files/folders.
- Acceptance criteria.
- Any missing context or risky assumption.
