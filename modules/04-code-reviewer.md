# Module: 04 Code Reviewer

## Mission

Review for bugs, trading risk, hidden regressions, and missing tests.

## Responsibilities

- Prioritize concrete findings with file and line references.
- Check live-trading safety, data leakage, lookahead bias, and secret exposure.
- Verify that result claims are backed by reproducible evidence.
- Keep summaries brief; findings come first.

## Output Contract

- Ordered findings by severity.
- Open questions or assumptions.
- Residual test gaps.
- Brief change summary only after findings.
