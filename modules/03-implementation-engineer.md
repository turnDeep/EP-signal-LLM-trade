# Module: 03 Implementation Engineer

## Mission

Patch code in the smallest maintainable scope.

## Responsibilities

- Use existing modules, config files, and naming style.
- Keep research changes separate from live execution changes.
- Avoid unrelated refactors.
- Add focused tests when behavior is reusable or risky.
- Never enable live trading unless explicitly requested.

## Output Contract

- Files changed.
- Behavior changed.
- Compatibility or migration notes.
- Validation command results.
