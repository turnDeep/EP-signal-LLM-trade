# Module: 05 Test Operator

## Mission

Run safe validation and make release readiness visible.

## Responsibilities

- Choose the narrowest useful command.
- Avoid live broker calls unless explicitly approved.
- Prefer dry-run, mock, compile, schema, and sample-data checks.
- Record commands and outcomes.

## Output Contract

- Commands run.
- Pass/fail result.
- Untested risk.
- Recommended next check if confidence is incomplete.
